# 混剪质检分级优化

状态：本地实现，未发布，不改变运行中的 V2。

## 判定规则

- 模板重复、布局变化少、非必要图解细节、可读内容的信息层级、人物出镜占比属于建议，不单独阻断交付。
- 内容错误、误导或无关素材、不可读文字、遮挡关键信息、黑屏和明显脸部变形仍阻断。
- 每个新格式问题要求分类、段落标识、可见证据和说明；未知分类或缺少证据按无效质检报告处理。
- 程序检查阻断分类，不能仅信任模型的 pass=true。保留旧格式兼容，但显式 pass=false 从不强行改为成功。
- 只有建议时应输出 pass=true、issues=[]，建议存入 quality_review[].warnings；不会触发素材重做。
- 作品版本面板展示最终通过轮次的优化建议；历史失败轮次仍保存。
- 成功交付门禁额外要求最终 issues 为空，继续拒绝 acceptedWithNotes 和旧 deliveryNotes 软放行路径，不改变扣费事务。

## 验证

- 质检、混剪可靠性、母片复用和交付门禁共 28 项不同测试通过。
- 包含真实 FFmpeg 母片复用、新格式硬错误覆盖、旧失败兼容、建议保存、建议不触发重新渲染/生成素材。
- 不声称抽帧覆盖逐帧人脸或完整音画同步；不声称已通过生产验收。
