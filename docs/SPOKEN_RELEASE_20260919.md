## 发布中发现并修复

1. 生产代理仍把口播能力统一返回 404，开发模式曾绕过。已放行获准上线的口播路由，保留路由自身鉴权和未发布编辑器的隔离，并补充生产模式回归。
2. 口播 CLI 子进程未继承 PPT 已使用的代理，导致规划调用超时。已补齐专用 host worker 的代理环境，真实智能生成随后成功。
3. 发布检查误读旧的无主机名后缀 Agent 心跳。已绑定当前容器身份，并保留版本、协议、新鲜度和必需依赖断言。
4. 生产 fixture 依赖被 standalone 内联的 JWT 模块。已改为 Node 内置 HS256 签名。
5. 媒体 fixture 的 Node fetch 未保留虚拟主机 Host，以及超限测试发送不完整请求体。已改为原生 HTTP 节点请求和真实有界流式上传，完整 17 条回归通过。

首次 host launchd bootstrap 的暂时失败已通过重试恢复。没有执行 Web 版本回滚；检测问题后使用向前修正版发布。
