# 本地口播视频 Agent 当前创作流程

核对日期：2026-09-20。适用 `spoken_video_v1`，执行入口 `scripts/spoken-video-production.mjs`。

## 1. 用户提交与校验

用户选择口播照片、我的声音、横竖画幅和制作方式，填写标题和定稿文案。基础版 50 积分，使用原智能版的语义节点、联网资料、授权素材、知识图解和成片审查能力；智能版 100 积分，在此基础上生成导演镜头脚本、知识点证据包、官网证据画面和切点前后连续质检。服务端按所选方式校验积分余额与 Agent 能力，并在任务创建时锁定价格和模式；仅在视频成功完成后扣费。其他校验包括应用访问资格、资产归属、声音就绪状态；清理 Markdown，锁定实际口播文字。当前只接受 HeyGen 声音，不会在这条流程内自动迁移禅境声音。

## 2. 创建和领取任务

服务保存视频任务与提交时价格，将 `digital-human.video.produce` 放入本地任务队列。Agent 领取租约，持续报告心跳、任务进度和错误。标准新任务只尝试一次；已有远端任务 ID 的恢复路径会继续轮询，不重新提交 HeyGen。

## 3. 分镜规划

程序先按句子合并为最多约 8 段；Codex 保持各段原文与编号不变，再拆成连续、无改写的语义节点，为每个节点生成素材搜索词、画面主题和可直接引用的知识卡片要点。两种版本均使用该语义节点作为剪辑基线。智能版额外为每个节点指定叙事角色、画面类型、人物布局、切换方式、证据 ID、生成提示词和导演说明；方案不能改变原文、顺序或节点数量。

## 4. 人物与 HeyGen 口播母版

优先使用用户选定照片；模板附带换脸照片时同样使用该照片。将人物照片／可用头像、锁定文案、HeyGen 声音与画幅提交给 HeyGen，请求 SRT 字幕。通常只产生一次 HeyGen 视频合成任务。Agent 轮询结果，下载并归档干净口播母版。完成母版后再准备外部素材与知识卡片，后期以母版实际总时长安排画面。

## 5. 外部素材检索与知识卡片兜底

每段先按英文画面关键词检索 Pexels、Pixabay、Wikimedia Commons 和 Openverse 的图片／视频。筛选标题相关性、授权、尺寸和文件大小，保存来源、授权与作者信息；Pexels、Pixabay 需配置各自 API Key，缺少时跳过。Commons/Openverse 接受可用于商业改编并可履行署名要求的授权，不限于 CC0／公有领域。

两种版本均把口播节点交给 Codex 进行实时信息获取；Codex自行制定查询、打开来源并追查线索，优先寻找政府、监管机构、协会、品牌、产品和原始发布者官网，再寻找报告／PDF、图片与视频参考。程序核对数字、时间和语义并保存可点击来源。网上图片和视频仍标记为授权待核实，不会因为搜索命中就自动混入成片。

智能版把检索结果进一步整理为知识点证据包，保存声明原文、来源标题、URL、摘录、资料类型、官方身份、权利状态、主来源和核实状态。Codex导演只能在存在有效证据 ID 时选择官网证据镜头；本地组件把原始摘录、标题和来源域名准确排成证据画面。流程不让图片模型生成条款、数字或来源文字，也不把AI情境图当成证据。事实型节点没有可靠来源时标记为需复核，不伪造引用。

未找到合适素材时，调用已配置的图片模型生成与知识点对应的原创插画背景，再准确排入该分镜的中文标题与要点，避免模型生成中文错字。智能版对数据和抽象金融概念优先走原创图解，图片模型可以读取已核对的文字资料摘要以决定画面关系，但不能复刻网上图片、文档版式或标志。竖屏知识卡根据内容使用大字数据、重点句、编号要点等不同布局；一条最值得记住的要点突出显示，其他原文要点作解释。画面直接面向观众，不出现“口播知识卡”“摘自本段口播原文”等制作说明，并预留右下角人像与底部字幕区域。图片模型不可用时退回本地排版卡片。卡片是原口播的整理，不能把没有可靠来源的口播事实当作已核实。


## 6. 本地剪辑

FFmpeg 按语义节点组合全屏人物、人物画中画、官网证据、素材和知识图解。基础版保留原智能版的语义混剪和短淡化；智能版以硬切为默认，标题缩短为约 1.25 秒，只有导演明确判断为时间或情绪变化的镜头才保留淡化意图。横竖规格分别为 1920×1080、1080×1920，30fps。

智能版导演还可使用三种人物持续出镜的复合镜头：场景素材浮窗 `presenter-overlay`、短数字／单结论挂件 `presenter-data`、短官网摘录 `presenter-evidence`。浮窗从侧边进入并在退出前淡出，始终位于字幕安全区上方；复杂图解、长证据和多步骤机制仍使用整屏，避免缩小后不可读。基础版暂不启用这三种导演布局。

当前分镜时长按文案字数占总时长的比例分配，尚未逐句根据语音做强制对齐。这与字幕使用的时间轴是两件事。

## 7. 字幕与包装

优先使用 HeyGen SRT，按标点和词语重排，每屏原则上最多 14 字，保护小数与数值单位并减少句尾孤字。字幕透明底、白字、细黑描边，无背景条、无阴影。没有可用 SRT 时才按文字比例生成粗略时间轴。

开头约 4.5 秒显示标题块，导出 MP4 并截取封面。当前不加入背景音乐。此次重剪使用已保存的字幕时间轴和干净母版。

## 8. 验收与修订

程序检查文件体积、时长、字幕长度、镜头时间轴连续性及全片解码；抽取语义节点中间帧，并加入代表性切点前后帧交给 Codex 检查素材相关性、信息量、构图、字幕可读性、人物连续性和镜头交接。对数据、抽象概念或不贴题的库图，验收优先要求重做原创知识图解；只有具体场景才继续换检索词。还可以调整人物比例和字幕长度，最多三轮；仍不通过则失败，不发布成片。

知识卡片兜底不会再被自动换成缺少实际信息的 AI 情境图。检索重试若得到内容相同的卡片，不能只因临时文件名不同就认定有实质修复。当前验收仍是抽帧，不是逐帧观看或精确嘴型同步检测。

## 9. 归档与计费

验收通过后保存 MP4、封面、素材来源清单与质检记录，标记完成。基础版 50 积分／条、智能版 100 积分／条，提交时保存所选价格；数据库 `charge_completed_digital_video` 触发器在任务转为完成时写入使用记录，唯一索引阻止重复计费。失败不触发该完成扣费。

现有视频支持在“我的作品”中反复提交剪辑修改，复用母版与字幕，不再调用 HeyGen。每次修改创建独立版本，保留全部旧版，支持预览、下载和设置当前版本；修改任务当前不重复收取首次生成积分。详见 [知识图解与多版本修改](./SPOKEN_VIDEO_VERSIONS.md)。
