# 通用混剪表达与质检分级

## 范围

- 关系规划与行业解耦：对比、顺序、时间线、因果、组成、要点、人物。
- 结构化节点必须完整复现对应原文，关系必须附原文证据；不完整或无依据时退回完整原文。
- 程序绘制准确文字及连接关系，不让图片模型承担数字、条件或逻辑文字。
- 两种画幅在字幕安全区之外排版；文字或不可拆词无法容纳时退回原母片，不截断、不缩到不可读。
- 基础版、智能版和二次混剪共用；新口播创建路径不变，二次混剪仍只读归档母片。
- 配图仍可使用已有素材来源；本轮不声称对任何行业语义都能确定性验证，关系解释仍需最终质检。
- 审美建议独立存储与展示；内容错误、误导、不可读、遮挡和脸部异常仍拦截。显式失败和带硬错误的通过报告不能成功交付。

## 回归范围

- `spoken-video-expression.test.mjs`：产品、办事、学习、生活、饮食、风险条件等跨题材原文；错误证据、遗漏条件、超长文字、两种画幅像素检查。
- `spoken-video-layout.integration.test.mjs`：真实 FFmpeg 字幕/PIP 安全区、片段缓存、基础版母片降级。
- `regression-video-delivery.mjs`：隔离账户、实际 HTTP 交付与计费、持久化、失败与建议的刷新展示、移动端溢出。
- 复用 `spoken:master-reuse` 与 `spoken:quality-delivery` 回归目录；catalog decision 为 existing coverage extended，maintenance 为 merged。

## 限制

结构校验不能证明因果关系真实性；最终模型抽帧质检也不是逐帧人脸或音画同步证明。本轮不降低真实性与可读性底线，不承诺首次成功率。
