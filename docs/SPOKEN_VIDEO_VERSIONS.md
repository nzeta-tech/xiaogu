# 口播视频：知识图解与多版本修改

2026-09-18，本地实现。

## 用户操作

“制作新视频”用于选择照片、声音和定稿文案。“我的作品”把同一作品的所有版本放在一起，支持切换预览、下载指定版本、设为当前版本。

在已完成版本上点击“调整这个版本”，输入修改要求或使用快捷建议。新任务另存为 V2、V3……；旧版本始终保留，制作中仍能播放已有版本，失败版本可以基于原版本重新修改。支持知识卡视觉风格、素材替换、字幕大小与断句长度、开头标题文字／时长／隐藏、全屏人物与素材的展示比例。口播文案、声音和人物不重新生成。

界面不展示 Codex、Agent、验收轮次、内部素材标识或原始服务错误。外部素材的署名仍可展开查看。

## 知识图解

无合适素材时调用应用已配置的图片模型，按分镜知识点生成专题插画与视觉背景，中文标题、原文要点和数字由本地排版叠加，防止模型错字。画面不出现“口播知识卡”“摘自本段口播原文”等制作说明。模型不可用时退回可读的本地卡片；不因此重新生成口播母版。

已生成的素材会作为私有媒体归档，分镜清单保留 mediaId。修改版默认复用未受影响的素材，只对要求修改的部分重新制作。旧版本没有归档素材时，需要重新准备对应画面；有保存的字幕则直接沿用，没有时尝试读取已有 HeyGen 任务的字幕，始终不提交新的 HeyGen 视频。

## 版本与权限

版本使用独立 digital_human_video_jobs 记录和独立 output／cover 文件；request_json 保存 root_job_id、base_version_id、revision_number、edit_instructions、selected_version_id 等。父作品加行锁，数据库索引防止同一作品同时修改、重复请求和重复版本号。根作品和旧版媒体不会被覆盖。

POST `/api/digital-human-videos/:baseId/versions` 接受 instructions 和 requestId；PATCH `/api/digital-human-videos/:rootId/versions` 接受 versionId。必须登录并拥有对应作品；创建修改版继续遵循既有应用访问资格。新版本仅携带 jobId 与 mode=recut，工作器从服务端读取锁定原文、母版和基础版本设置，客户端不能传入 voiceId、script 或母版地址。

当前修改任务 quota_cost=0，不重复收取首次整条口播生成的 50 积分；没有更改应用访问政策或已有计费记录。后续如果要对图片生成／修改另行计费，需要单独定义价格。

素材上传接口拒绝修改已完成作品，修改版不能上传 presenter_master。归档下载按媒体所有者校验，选择当前版本也校验归属和完成状态。

迁移：087_spoken_video_versions.sql。此次本地还补齐了既有 086 访问资格依赖表，没有改变真实用户的访问权限。未发布生产环境。
