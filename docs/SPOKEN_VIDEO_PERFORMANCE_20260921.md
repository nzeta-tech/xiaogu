# 1080p 口播制作优化与三轮发布

## 发布语义

- 输出保持竖屏 1080×1920 / 横屏 1920×1080。
- 每次制作最多三轮导演质检。通过即交付；第三轮不通过也返回 completed，保留真实 pass=false、issues 和 delivery_notes，前端显示“已发布 · 质检仍有待改进项”。
- 质检服务异常会记录“质检未能完成”，不能冒充通过。无可执行修改、reviewOnly 时复用已有成片继续复核，不无意义重复编码。
- 必须有可播放成片并通过技术检查。生成失败、无法解码、空文件、时间轴不完整不会伪装成已发布。
- completed 沿用既有完成入库、版本选择和计费逻辑，不代表已发到外部社交平台。

## 渲染与预检

- 无叠化的常用智能版默认单次 FFmpeg 合成：连续母版 + 卡片/素材时间表 + 画中画 + 字幕/标题。音轨始终来自完整母版，避免分段 AAC 编码切点。
- 带叠化的路径仍使用内容寻址分镜缓存；renderStrategy=segments 可用于对照与回退。
- 编码器 auto 在 macOS 实际探测 VideoToolbox；其他平台默认 libx264。可显式选择 h264_nvenc。探测失败或实际编码失败自动回退 libx264；不把“支持编码器名称”当成硬件可用。
- 渲染前使用字幕吸附后的真实时间轴检查空隙/覆盖与连续全屏长度。超过 12 秒时使用内容与主播互不遮挡的画中画布局。保留口播和素材。
- 知识卡使用字幕/画中画之外的区域，背景延续素材主色；场景照片不被当成文字卡缩小。
- 本地 SVG 模板对文字估计边界做适配，完整保留文字；这不是对外部图片的 OCR，也不替代视觉复核。
- 移除 V20 的“小谷｜家庭财务观察”和 V3 的“家庭财务观察”固定栏目署名。已有历史成片不重写。

## 复用与质检

- 分镜和无叠化整片使用内容哈希缓存，包含母版/素材内容、时间、尺寸、字幕、标题、布局、编码策略与版本。缓存附带摘要，损坏时重新生成；成功后原子发布。
- 生产共享缓存按服务端地址和任务所有者隔离；未提供所有者时退到 jobId，不跨未知用户共享。
- 素材缓存将产物复制到持久目录，不依赖已清理的临时任务目录。研究/规划结果有效期 24 小时；素材有效期 24 小时。媒体缓存每个目录按 7 天、4 GiB 清理，活跃目录清理节流为 1 小时。
- 研究步骤使用两个隔离工作目录并发，保留逐段检查点。修改版不再因旧元数据缺失而强制重做全部素材；仅重新研究和规划实际改动的片段。
- 后续轮次向导演提供变化镜头、相邻镜头及上轮问题，仍提供全片联系表和完整时间轴，复核未解决的问题与全片连续性。
- 字幕/标题/布局等全局参数变化时全量复核。局部修改时复用时间与内容未变化的质检帧，重抽变化镜头、邻接镜头和转场样本。
- 大批量抽帧默认一次解码；少量抽帧或批量失败使用两个 seek 工作进程。LOCAL_AGENT_VIDEO_FRAME_MODE=seek 可强制对照。

## 耗时观测

- 结果 performance 记录真实 wallMs、阶段 offsetMs、elapsedMs、成功与否，以及编码、模型、技术检查、抽帧、缓存命中等事件；后端保存在 request_json.performance。
- 阶段存在并行和嵌套，不能把全部 elapsedMs 相加当作总等待时间。wallMs 不含领取任务前的排队；前端“已等待”从任务创建时刻计算，包含排队。
- LOCAL_AGENT_VIDEO_REVIEW_TIMEOUT_MS 默认 120000，限制为 30–240 秒。CLI 超时但已写出有效质检报告时复用报告。

## 本地验证

基准工具：

```sh
node scripts/benchmark-spoken-video.mjs <已有 result.json> <新的输出目录>
node --experimental-strip-types --test scripts/spoken-video-*.test.mjs src/lib/local-agent/video-completion*.test.mjs src/components/pages/spoken-video-delivery.test.mjs
npm run typecheck
```

基准只读母版和素材，不调用生成模型、不上传、不发布，不启动/停止 Agent。记录保存于 artifacts/spoken-performance-20260921/benchmark.json。样片为 124.47 秒，22 个语义分镜。

本地对照结果：分镜路径首次合成 204.2 秒、已有分镜缓存时重新整片合成 97.7 秒；单次合成路径分别为 167.9 秒和 4.8 秒。首次制作本次约缩短 18%；完全相同内容的再次导出约缩短 95%，不代表修改了卡片后也能在 4.8 秒完成。

首组本地观测：单次合成约 167.9 秒，完全相同内容缓存命中约 4.8 秒；批量抽帧 17.2 秒、双并发 seek 18.1 秒。当前主机 VideoToolbox 会话创建失败，实际使用软件编码。这是一次开发机观测，期间也有本地回归负载，不能作为生产 SLA 或严格隔离的性能对比。

回归结果：92 项通过、0 项失败；其中 PostgreSQL 计费集成测试因未配置专用测试数据库跳过。真实 FFmpeg 测试覆盖横竖屏字幕/PIP安全区、镜头切换、连续音轨、质检帧复用、批量抽帧及修改版素材复用。类型检查通过。

本轮只修改工作区并本地验证。上线必须另外通过 xiaogu-deploy 不可变发布流程，不覆盖 current runtime，也不直接重启生产 Agent。
