# 口播视频生成应用改版方案（Review 草案）

## 资产流程更新（2026-09-17）

实际入口已收敛为“我的口播照片”和“我的声音库”。照片可直接上传；已有禅境形象只取静态照片，支持上传第二张授权照片调用图片模型换脸，生成结果保存为新的口播照片。声音可按五段约两分钟文案在浏览器录制，试听后保存并提交 HeyGen 克隆，完成后可重命名和用于口播；也可从禅境声音库收藏。视频生成第一步从口播照片库选择或上传，第二步从声音库选择。下文三来源设计为早期草案，以本节和当前实现为准。

## 目标

用户只需选择人物、选择声音、填写口播文案并点击生成。系统先按口播文案搜集并核验相关文字、图片和视频素材，形成可执行的画面方案，再由本机 Codex 调度一次 HeyGen 口播合成，最后完成素材混剪、字幕、包装、检查和 MP4 导出。页面不再出现“快速生成 / 智能创作”模式切换。

## 用户流程

| 页面步骤 | 用户操作 | 默认行为 |
| --- | --- | --- |
| 1. 选择人物 | 三选一：我的数字人；我的视频模板；直接上传照片 | 只允许选一种来源，切换来源时清除上一来源的选择 |
| 2. 选择声音 | 从“我的声音”中试听并选择 | 已有数字人可默认选其绑定声音；其他来源必须明确选一个可用声音 |
| 3. 填写内容 | 输入标题和口播文案，预览清理后的纯文本 | 保留原文语义和句序，只去除 Markdown 语法；提交后锁定本次口播文本 |
| 4. 生成与查看 | 点击一次“生成视频”，查看进度和结果 | 输出可预览、下载的 MP4，失败时显示具体阶段及可重试操作 |

### 第一步的三种人物来源

1. **我的数字人**：沿用当前资产列表、预览和版本信息。提交前检查此资产能否用于 HeyGen；不能使用时明确提示并提供转换或重新创建入口，不静默改用其他人物。
2. **我的视频模板**：沿用当前收藏模板列表与预览。模板决定画幅、画面结构和视觉风格。模板人物区域上方提供“上传换脸照片（可选）”：一旦选中照片，页面明确显示“将用这张照片替换模板出镜人物”，提交载荷锁定该照片 ID；后台必须完成替换并校验最终人物，不能在失败时静默退回模板原人物。未上传照片时，使用模板原有人物或要求用户补选人物，取决于该模板是否允许复用原人物。模板必须增加 `renderType`、人物占位符和可替换能力等元数据，不能仅凭现有封面、名称和 `structure` 当作可换人的生成模板。
3. **直接上传照片**：上传一张清晰单人照片，预览裁切，作为本次口播的人物来源。照片是一次性任务素材；用户可选择完成后另存为“我的数字人”。

所有上传照片都先校验格式、大小、清晰度、单人主体及使用授权。界面里将“换脸”准确表达为“用我的照片替换模板出镜人物”，避免让用户以为会修改任意现成视频中的脸。选中照片后，预览、任务详情和最终结果都展示本次使用的照片，便于用户核对。

## 后台生成链路

| 阶段 | 执行方 | 产物与检查点 |
| --- | --- | --- |
| 1. 文案准备 | 本机 Codex | 纯文本口播稿、标题、不可变文本指纹；去 Markdown 后供用户确认 |
| 2. 内容拆解与素材搜集 | 本机 Codex | 按口播段落抽取主题、事实、比喻与解释难点；搜集相关文字、图片、视频，留下来源、授权和适用段落 |
| 3. 素材筛选与画面预案 | 本机 Codex | 核对文字事实和时效，筛选清晰且可用的素材，为每段确定“人物主画面 / 视频镜头 / 图片 / 图表或信息卡”，形成素材清单和镜头顺序；缺口在合成前补齐 |
| 4. 资产解析 | 服务端 + 本机 Agent | 人物来源、HeyGen 可用身份或图片、声音 ID/音频、模板映射、画幅；禅境旧资产按下文转换；模板换脸照片有独立的强制校验 |
| 5. 口播母版 | 本机 Codex + HeyGen | **一条 HeyGen 合成任务**，得到完整口播视频、音频、封面；持久化远端任务 ID 以便恢复和防重复提交 |
| 6. 画面编排 | 本机 Agent + FFmpeg；复杂动效可选 HyperFrames | **每条视频默认混剪**，按预案插入图片、视频、图表或信息卡；素材覆盖口播画面时，把数字人放在右下角圆形浮层；安全区避开字幕和标题 |
| 7. 中文字幕 | 本机 Agent | 优先读取 HeyGen 返回的 SRT/字幕时间轴；缺失时对口播母版做本地强制对齐；校对时间、错字并烧录一次，避免双重字幕 |
| 8. 后期包装 | 本机 Agent | 添加标题、单独导出封面，统一人声响度及 9:16/16:9 规格；素材原声默认静音，本版不添加背景音乐 |
| 9. 质检与导出 | 本机 Agent | 检查素材是否贴合对应口播、时长、黑帧、字幕边界、嘴型与音频偏移、浮层遮挡；保存母版及最终 MP4，向应用回传结果 |

统一使用一个任务状态机：`排队 → 准备文案 → 搜集素材 → 核验并锁定画面预案 → 转换人物和声音 → HeyGen 合成 → 本地编排 → 字幕与包装 → 质检 → 完成/失败`。每阶段保存进度和中间产物；重试从失败阶段恢复，不重复扣费提交 HeyGen。

### 素材搜集与筛选细则

1. **理解口播**：以锁定的纯文本为准，按意思而非固定秒数分段。每段标出核心信息、需要视觉解释的概念、可视化形式和搜索词。例如“家庭教育金储备”可找家庭学习场景、教育支出构成图；数字、条款、收益类内容优先用可核查的文字或图表表达。
2. **分层搜集**：先查用户自己的素材和已授权本地素材库，再查有明确使用许可的图片、视频来源。文字事实优先查原始机构材料或用户提供的资料；不把搜索结果摘要直接当事实。为每个素材保存原始链接/本地路径、作者或机构、授权范围、获取时间和对应文案段落。
3. **质量筛选**：文字检查事实、日期、数字和与口播是否一致；图片/视频检查清晰度、主体、画幅、可裁切区、时长、画面连贯性和水印。剔除低清、重复、与内容无关、无法确认使用权或会误导保险/财经理解的素材。
4. **生成画面预案**：每段优先选一项能帮助理解的画面，而非仅按关键词堆素材。人物开场和转折保持完整主画面；解释场景用实拍或图片；数字关系用图表或信息卡。明确镜头用途、预计时长、文字显示内容和右下角浮层安全区。预案锁定后才提交 HeyGen，后期按真实口播时间轴微调切点。
5. **补缺和降级**：查不到合格实拍时，用有来源的文字事实制作图表、示意图或信息卡；不使用未经核实的数值，不为了凑混剪插入无关画面。若关键事实或许可无法核实，任务停在素材审核阶段并提示用户补充资料。

素材清单建议以 `segmentId / scriptSpan / kind / source / rights / evidence / relevance / quality / localPath / plannedDuration / crop / status` 存储。图片、视频文件落本机缓存，文字证据与视频画面分开保存，方便复查、替换和重复利用。当前仓库已有的数字人背景与风格参考图仅覆盖静态示例，不能当作完整的视频素材库；需要新增可搜索的视频、图片和证据素材索引。

页面仍只保留一次“生成视频”操作。生成记录展示“正在搜集素材 / 已找到多少段可用画面 / 正在合成口播 / 正在剪辑”等进度；结果页可展开查看素材来源及对应段落，并允许替换单个不合适的镜头后仅重做本地后期，无需重新提交 HeyGen。

## 基于现有代码的改动范围

- 前端：改造 `DigitalHumanVideoPageClient`，移除 `creationMode`、智能分镜确认及现有复杂画面设置；把人物来源改为三选一，声音独立成为第二步，保留生成记录和结果预览。
- 服务端：把视频创建请求统一为 `personSource`、`voice`、`script`、`template`、`photo`、`outputOptions`；上传照片先落到受控媒体存储，再创建任务。服务器只负责鉴权、校验、排队、状态和成果存储。
- 本机 Agent：在现有 `heygen.video.generate` 与 `xiaogu.video.compose` 前新增素材搜集、核验与画面预案阶段，或用一个编排任务串联所有阶段；Codex 负责素材决策，FFmpeg 负责稳定的剪辑、圆形画中画、字幕和人声响度处理。HyperFrames 用于确实需要模板化动画、图表或复杂视觉包装的场景，不成为基础成片的强依赖。
- 数据：为视频任务记录人物来源、模板版本、照片媒体 ID、声音来源、锁定文案、素材清单与画面预案、HeyGen 任务 ID、字幕文件、母版、最终成片、失败阶段及重试次数。素材库记录可用主题、画幅、时长、来源和授权信息。

### 与现有本地 Agent 的关系

新视频生产 Agent 使用**现有小谷本地 Agent 的控制面**，注册为独立能力和独立 Worker；不再造一套登录、队列、回调或浏览器与本机直连协议。Web 服务仍是任务和状态的权威来源，本机 Worker 只通过出站 HTTPS 领取任务、更新进度、上传成果。视频 Worker 与 `source.inspect`、`ppt.generate`、`openchatcut.edit` 等是同级执行能力，不是这些 Agent 的子任务。

```text
口播视频生成页面 → Web API / 视频任务记录 → 现有 local_agent_tasks 队列
                                           ↓
                             专用 digital-human.video.produce Worker
                             ├─ 素材搜集与核验（Codex + 素材索引）
                             ├─ 人物与声音准备（旧资产转换）
                             ├─ HeyGen 口播合成（复用现有执行器）
                             └─ 本地后期（扩展现有 FFmpeg 执行器）
                                           ↓
                             现有媒体上传接口 → 视频任务状态 → 页面
```

| 现有能力 | 复用方式 | 仍需新增或重构 |
| --- | --- | --- |
| `local_agent_tasks` 队列、租约、心跳、重试、任务事件、能力健康检查 | 直接复用任务调度和用户可见进度 | 注册视频生产能力；按阶段保存检查点及幂等键，避免重试重复提交 HeyGen |
| `heygen.video.generate` | 复用本机 Codex CLI、HeyGen 登录/技能通道、单条口播任务与进度回传 | 扩展照片、模板人物替换、旧禅境人物/声音输入；完成后只标记“口播母版就绪”，不能提前把整个视频任务标记完成 |
| `xiaogu.video.compose` | 复用 FFmpeg、母版下载、媒体上传、画幅处理和图层合成基础 | 增加真实图片/视频混剪、圆形人物浮层、字幕、标题、封面和逐段质检；当前实现主要是静态信息卡叠加 |
| `source.inspect` 与本地浏览器/下载组件 | 可复用安全下载、媒体信息提取和转写的底层工具 | 新建有来源与使用权记录的素材发现/筛选逻辑；`source.inspect` 本身不是通用版权素材搜索器 |
| 本地 `transcriber`（Whisper） | 复用为 HeyGen 无字幕时的中文转写备选 | 增加按锁定文案的时间对齐、校字和 SRT 生成；现有流式转写不能直接等同成品字幕时间轴 |
| `openchatcut.edit` | 以后若用户要继续手动编辑，可把成片及素材导入可编辑工程 | 自动成片不依赖 OpenChatCut，避免编辑器状态成为基础生成的单点故障 |
| `ppt.generate` | 复用隔离临时目录、Codex CLI 执行和成果校验的运行模式 | PPT 业务逻辑不进入视频流水线 |

视频渲染、搜索和 Codex 调用都可能长时间占用资源，因此视频 Worker 应使用独立 `LOCAL_AGENT_CAPABILITIES` 和并发限制，与现有抓取/转写 Worker 分开运行；但共享同一任务协议与 Web 状态。生产和测试仍按现有本地 Agent 环境隔离。当前 `heygen.video.generate` 完成时会把视频任务直接写成完成，`xiaogu.video.compose` 是智能模式之后的补充任务；改版时需要把两者收进一条持久化父任务，最终 MP4 上传并质检通过后才写“完成”。

### 禅境旧资产接入 HeyGen

用户仍可选择现有禅境数字人及其声音。生成任务先取得该资产的原始上传照片/视频和原始声音样本（优先使用小谷已保存的源素材；缺失时尝试供应商允许的导出），保存为本次受控临时素材。人物侧从合适的帧提取照片或使用原始照片，创建 HeyGen 可用的图片/形象；声音侧优先转换为 HeyGen 可用声音。如果只有禅境声音 ID、没有可导出的声音样本，则用该声音为**本次锁定口播文案**合成音频，再把音频交给 HeyGen 做嘴型同步。HeyGen 视频接口支持传入音频文件与传入文案二选一；此路径仍只有一次 HeyGen **视频**合成任务。[HeyGen 视频接口](https://developers.heygen.com/reference/create-video)

转换结果按原数字人和声音 ID 缓存，后续任务复用。转换前检查用户授权、源素材可用性及账号实际能力；如果无法取得人物或声音素材，任务停在资产准备阶段并说明原因，绝不自动换成其他人或其他声音。要用一条旧禅境数字人加旧声音的真实任务验证这一整条链路，再对所有旧资产开放。

## 先验证的关键问题

1. **供应商分工**：HeyGen 负责唯一的口播视频合成；禅境保留旧资产读取，必要时为已选禅境声音生成本次文案的音频。旧禅境 ID 不能直接当成 HeyGen ID，必须经过上述素材取得和转换流程。该链路以实际账户权限和一条端到端样片为验收门槛。
2. **模板定义**：现有“我的视频模板”是参考模板，需逐个标记能否直接替换人物。HeyGen 的模板生成接口支持人物变量，但前提是模板本身已定义相应变量；不能承诺所有现存模板都能换人物。[HeyGen 模板文档](https://developers.heygen.com/template-api)
3. **直接照片**：HeyGen 当前视频接口描述支持从任意图片生成视频；仍需在本机账号和当前 Codex/HeyGen 通道上做一次实际任务验证，包括照片、声音、授权和费用路径。[HeyGen 视频接口](https://developers.heygen.com/reference/create-video)
4. **字幕来源**：HeyGen 视频查询结果包含字幕 URL 字段；要实际验证所用通道是否稳定返回中文时间轴。若没有，走本地对齐。[HeyGen 视频查询接口](https://developers.heygen.com/reference/get-video)
5. **本机可用性**：提交前显示 Codex、HeyGen、FFmpeg 和本机 Agent 的实时健康状态。设备离线时不接受无法执行的任务，或清楚标记为排队等待。

## 建议验收标准

- 三种人物来源各成功导出一条视频；模板照片替换时最终人物与上传照片一致，模板结构仍保留；替换失败不能输出模板原人物成片。
- 一条现有禅境数字人加其声音成功走通素材取得、转换、HeyGen 合成和本地导出，人物与音色均与所选资产一致。
- 同一条任务只创建一次 HeyGen 合成；重试本地后期不再重复提交。
- 素材搜集和画面预案在 HeyGen 提交前完成；抽查每段能说明素材为何相关，以及文字事实和使用权的来源。
- 每条视频都有素材混剪或信息卡；字幕与口播逐句对应，成片没有双层字幕；素材镜头出现时右下角数字人持续可见，且不遮挡字幕。
- 浏览器关闭后任务继续执行；刷新后进度、错误和最终 MP4 仍可查看。
- 对不可用的旧资产、声音和模板，在生成前给出清楚的原因与下一步操作。

## 已确认的产品规则

1. 模板模式下换脸照片可选；一旦选择，人物替换成为必须成功的生成条件。
2. 禅境旧资产在生成流程里取得人物和声音素材，再转换或交给 HeyGen；任何不可导出的情况明确失败，不悄悄改人或改音色。
3. 每条视频都默认混剪；素材画面中始终保留右下角圆形数字人浮层。
4. 先按口播文案搜集高质量文字、图片和视频素材，审核并锁定画面预案，再开始 HeyGen 口播合成。
5. 当前版本不添加背景音乐；最终成片以所选人物声音的口播为主，素材视频原声默认静音。
